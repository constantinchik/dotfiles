# Vault access
Use `obsidian` with vault-relative `path=` or wikilink-style `file=`; the desktop app must be running. The old Local REST API MCP is deprecated here. If CLI access fails, report it rather than switching to direct vault files.

Commands and local lookup/move gotchas: `references/cli.md`. Before writing, load `personal-obsidian-vault`; no dedicated note-taker agent is required.
