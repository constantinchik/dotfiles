# Where knowledge lives
Project/device/room/order notes and prior research live in the Obsidian vault: use `obsidian` search/read. Follow links from relevant notes, not only the first search hit.

A separate LLM wiki is not assumed configured; adopt its schema/index only if its location is established. Private agent memory and conversations are not that wiki.

The existing `ask_hermes` MCP delegates actions to Hermes; it is not read-only knowledge search. Local clients use the shared skills and CLI directly.
