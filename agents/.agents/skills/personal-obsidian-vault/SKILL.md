# Note conventions
Use `obsidian` CLI. Direct note-edit requests cover that note scope; inferred wrapups need Save/Skip/Modify approval. No automatic daily note or backlink sweep.

Routing/formatting: `references/note-recipes.md`. Purchased hardware: `templates/hardware-inventory-note.md`. Explicit SMB/iCloud test copies only: `references/icloud-vault-copy-to-smb.md`.

Search for matching notes before creating; read/preserve existing content before updating. Read back writes through the CLI. Use plain wikilinks in tables and keep verified state separate from plans.
